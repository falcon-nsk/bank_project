# Виджет банковских операций
## Описание проекта
Учебный проект по разработке виджета банковских операций.

Виджет предназначен для отображения последних успешных банковских операций клиента в личном кабинете.

Приложение позволяет:
- маскировать номера карт;
- маскировать номера счетов;
- фильтровать операции по статусу;
- сортировать операции по дате.
## Установка 
1. **Клонировать репозиторий:**
```commandline
git clone https://github.com/falcon-nsk/bank_project.git
```
2. **Перейти в директорию проекта:**
```commandline
cd bank_project
```
3. **Установить зависимости:**
```commandline
poetry install
```
## Использование
Для работы с функциями обработки банковских операций необходимо импортировать модули `processing` и `masks`.
### Фильтрация операций по статусу

Функция `filter_by_state` возвращает список операций с указанным статусом.
### Сортировка операций по дате

Функция `sort_by_date` возвращает список операций, отсортированный по дате.
### Маскировка данных

Модуль `masks` содержит функции `get_mask_card_number` для маскировки номеров банковских карт и `get_mask_account` для маскировки номеров счетов.

## Декоратор log
В проекте реализован декоратор `log`, который автоматически записывает информацию о выполнении функций.

Декоратор поддерживает два режима:
- если указан `filename`, сообщение записывается в файл;
- если `filename` не указан, сообщение выводится в консоль.

При успешном выполнении функции записывается сообщение:

```commandline
my_function ok
```

При возникновении ошибки записывается тип ошибки и входные параметры функции:
```commandline
my_function error: division by zero. Inputs: (1, 0), {}
```

Пример использования:
```commandline
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y

my_function(1, 2)
```

## Тестирование
Для проверки корректности работы проекта используются автоматические тесты на базе `pytest`.

Запуск тестов:
```commandline
pytest
```

Для проверки покрытия кода тестами используется pytest-cov:
```commandline
pytest --cov
```
**Тестами проверяются:**
- Функции маскирования номеров карт и счетов;
- Обработка данных банковских операций;
- Фильтрация операций по статусу;
- Сортировка операций по дате;
- Преобразование дат;
- Генераторы для обработки банковских операций:
  - фильтрация транзакций по валюте `filter_by_currency`;
  - получение описаний транзакций `transaction_descriptions`;
  - генерация номеров банковских карт в заданном диапазоне `card_number_generator`;
- Обработка некорректных входных данных и исключений.

На текущем этапе покрытие тестами составляет 99%.
