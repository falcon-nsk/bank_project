# Виджет банковских операций
## Описание проекта
Учебный проект по разработке виджета банковских операций.

Виджет предназначен для отображения последних успешных банковских операций клиента в личном кабинете.

Приложение позволяет:
- маскировать номера карт;
- маскировать номера счетов;
- фильтровать операции по статусу;
- сортировать операции по дате.
## Установка 
1. **Клонировать репозиторий:**
```commandline
git clone https://github.com/falcon-nsk/bank_project.git
```
2. **Перейти в директорию проекта:**
```commandline
cd bank_project
```
3. **Установить зависимости:**
```commandline
poetry install
```
## Использование
Для работы с функциями обработки банковских операций необходимо импортировать модули `processing` и `masks`.
### Фильтрация операций по статусу

Функция `filter_by_state` возвращает список операций с указанным статусом.
### Сортировка операций по дате

Функция `sort_by_date` возвращает список операций, отсортированный по дате.
### Маскировка данных

Модуль `masks` содержит функции `get_mask_card_number` для маскировки номеров банковских карт и `get_mask_account` для маскировки номеров счетов.
